- 2026-11-03 01:49 PST: Exp 5 (prediction-error cost in a switching world) finished. No variant shows active recovery beating passive replay; every one gets the same passive label as Exp 4. Main arm sw_pecost_pe closed−open kick0.1 = +17.77 [+13.28, +22.27]; label: stable inherited dynamics. Committed to the public repo (README section, figures/exp5).
  - Details: all seven variants land in the same row (selection dominates, recovery passive). Charging for prediction error did lower late PE MSE (about 0.61 in sw_pecost vs 0.74 in sw_full), so the cost bit, but it did not make the closed loop damp kicks. sw_pecost is actually a bit worse than sw_full on kicks (paired Δ(closed − open) +2.40 [+0.85, +3.95]). Switching vs static layout made no difference to recovery (+0.13 [−3.55, +3.81]), and neither did heredity (vs shuffled, −2.50 [−10.0, +5.0]). Only the starvation-free control (sw_no_cost) is less amplifying. Price identity residual ≤ 2e-15 under standardized inputs. n = 3 seeds, so CIs are wide.
  - Next step, and why: three experiments in a row give the same answer, and in every one the closed loop amplifies hidden-state kicks because a perturbed agent moves differently and the coupled world diverges. Hidden-state distance may be the wrong yardstick for regulation. The most informative next run is to score recovery on the variables an agent would regulate (energy, intake and prediction error) against its unperturbed twin, and add a control where the perturbed agent's own world-coupling is cut (its actions still execute but its inputs are replayed), so world chaos is separated from brain dynamics. That reuses the existing sim5 forks and is cheap. More seeds would only tighten intervals around a consistent null.
